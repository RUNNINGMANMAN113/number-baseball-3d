# NUMBER BASEBALL 3D v40 — 경기 중계 및 공격모드 오류 수정

기준 버전: v39. 신규 게임 규칙·로스터·고화질 렌더링 설정·기존 저장 키는 변경하지 않았습니다.

## 수정 항목

1. **삼자범퇴 순서**: 마지막 아웃이 판정되면 투수 환호(`threeUp`)가 먼저 나오고, 이후 마지막 타자가 더그아웃으로 복귀(`batterExit`)합니다. 공수교대가 필요한 모드라면 그다음 이닝 전환을 재생합니다. 삼자범퇴가 아닌 세 번째 아웃은 전용 환호를 잘못 호출하지 않습니다.
2. **투수 교체 유니폼**: 기존 투수와 새 투수가 모두 *수비팀 색상*을 사용하도록 3D 엔진의 `incomingPitcher` 색상 매핑을 수정했습니다. 공격팀 선수는 기존 공격팀 색상을 유지합니다.
3. **중계 사이 경기장 화면 보호**: 정상 WebGL 렌더링 시 초기 경기장의 정지 화면을 한 차례 저장합니다. 메인 WebGL 컨텍스트가 손실되면 하얀 캔버스 대신 저장해 둔 경기장 이미지를 보여줍니다. GPU가 정상 복원되면 메인 3D를 다시 표시합니다. 초기 스냅샷 확보에 실패하면 경기장 색상의 간단한 배경을 대신 보여줍니다. 탭 전체가 종료되는 GPU 충돌은 자동 복구할 수 없으므로 기존 저장 후 재시작 기능을 유지합니다.
4. **숫자 1회 입력 → 투구 중계 1회**: 홈런 및 동점·역전 득점 후 같은 타격 장면을 자동으로 반복하던 `replay` 장면을 제거했습니다. `NBDirector`의 `READY` 메시지가 중복 전달돼도 같은 장면의 `PLAY` 메시지를 다시 보내지 않도록 중복 전송 방지 장치를 추가했습니다. 타자 퇴장·환호·교체 등 후속 *다른 장면*은 정상 연결됩니다.
5. **공격모드 컴퓨터 투수 교체**: 홈런 직후 법적으로 교체할 수 있고 남은 투수가 있을 경우 약 92%의 확률로 교체합니다. 그때 교체하지 않았더라도 `changeRight`가 남아 있는 다음 합법적 상황에서 다시 판단하도록 수정했습니다. 이닝 교대 시 교체 판단과 같은 입력의 후속 판단이 중복되지 않도록 했습니다. 실제 교체되면 `bullpenEnter` 장면을 별도로 재생합니다. 전략적으로 교체 후 비밀 숫자를 유지하는 확률을 18%에서 8%로 낮추되, 해당 전략 자체는 유지했습니다. 새 숫자를 선택하는 경우에는 기존과 반드시 다른 세 자리 숫자를 생성합니다. 투수 총 11명의 한도는 기존 규칙 그대로입니다.
6. **3B 장면**: 한 번의 추측 결과가 정확히 `0S 3B 0F`라면 `countTake`(타자가 지켜보기)만 선택합니다. 직전 장면 중복 방지 로직도 이 규칙을 덮어쓰지 않습니다. 4B 출루는 기존 볼넷 장면을 사용합니다. 이 변경은 외형적 애니메이션에 한정되며 판정 규칙은 바뀌지 않습니다.

## 유지된 사항

- 2인용, AI 대전, 1인용 공격모드
- 기존 S·B·F 판정, 9이닝 운영, 기본 경기 진행, 저장 키 및 로스터
- v39 고화질 그래픽, 타구 추적 카메라, 상황별 사운드
- 과거 버전 저장 파일의 기존 구조
