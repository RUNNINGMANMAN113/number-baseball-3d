# NUMBER BASEBALL 3D v41 — 선발투수 숫자 6개 시스템

- 선발투수는 최초 숫자 1개에 더해 교체 가능 조건 달성 시 최대 5회 숫자를 변경할 수 있습니다.
- 선발투수는 그대로 유지되고, 투수의 누적 경기 기록도 유지됩니다. 숫자 구간별 카운터만 새로 시작합니다.
- 같은 선발이 사용했던 숫자를 다시 선택하지 못합니다.
- 불펜은 최대 10명을 각 1개의 비밀 숫자와 함께 운용합니다. 선발+불펜 포함 팀당 최대 16개 숫자 운용 슬롯입니다.
- 새 투수에게 이전 투수 숫자를 유지시키는 기존 전략도 유지되어, 슬롯 수와 실제 서로 다른 값의 개수는 다를 수 있습니다.
- 2인용과 AI 대전에 선발 전용 비밀 숫자 교체 버튼을 추가했습니다. 공격모드 CPU의 자동 전략도 개편했습니다.
- '현재 숫자 상대 기록'은 선발의 숫자 변경 전후로 추리 내역을 분리합니다.
- 기존 저장 파일 v7 형식 호환, v40 로스터 및 고화질 3D 엔진 유지.

검사: Node VM 규칙 테스트 78개 통과, HTML 스크립트 문법 통과, 실제 브라우저 GPU 동작 미검증.
