# NUMBER BASEBALL 3D: FULL COUNT v3 — 6F 추가 아웃 제거 / 일반 아웃 연출 확장

## 무엇이 바뀌었나요?
- 누적 F 6개마다 발생하던 특별 아웃 규칙을 **삭제**했습니다. 파울 누적값은 아웃 여부를 결정하지 않습니다.
- 기존 3F 즉시 아웃, 누적 3스트라이크 삼진, 희생작전 결과 등 원래 아웃 판정은 그대로 유지합니다.
- 기존 6F 전용 연출 4개를 기존 아웃 애니메이션으로 옮겼습니다.
  - **삼진일 때**: 25% 확률로 포수 파울팁 포구, 나머지는 기존 헛스윙·루킹 삼진.
  - **주자 없는 일반 아웃일 때**: 1루수 직접 베이스 터치, 1루수→투수 베이스 커버, 투수 직선타 포구를 기존 뜬공·땅볼·직선타 연출과 함께 무작위 선택.
  - **주자 있는 일반 아웃일 때**: 기존 주자 보존 연출만 선택. 주자가 없다는 가정이 필요한 1루수 처리 장면은 사용하지 않음.
- 모션 선택은 **아웃이 이미 확정된 후** 일어나며, 추가 아웃·득점·주루 변화를 발생시키지 않습니다.
- 홈런을 많이 친 팀 승리, 볼넷 후 숫자 변경 없음, 홈런 후 세 자리 변경권, 첫 추리 60초/이후 45초 피치클락 및 KBO 팀 색상 기능을 유지합니다.

## 실행
모든 파일을 같은 폴더에 두고 `index.html`(2인용), `ai.html`(AI), `attack.html`(1인 공격)을 브라우저에서 실행하세요. `animation_engine.html`을 옆에 두어야 3D 연출이 표시됩니다. 외부 Three.js 로딩을 위해 인터넷 연결이 필요할 수 있습니다.

## 저장 호환
v3는 별도 저장 키를 사용합니다. 이전 v2 또는 v1 저장을 읽을 수는 있지만, 이전 경기에서 이미 기록된 6F 추가 아웃의 결과를 되돌리지는 못합니다. 이전 저장 파일은 덮어쓰지 않습니다.

## 주의
이 버전의 파울팁은 *삼진 확정 후에 보여 주는 연출 선택*일 뿐이므로 누적 F에 의해 새 삼진을 만들어 내지 않습니다. 다른 인플레이 아웃 연출도 해당 선수 기록을 별도로 가산하지 않고 기존 아웃 결과를 표시합니다.

## 3D 연출 확률 (실험용)
- 일반 숫자 삼진(번트 제외): 파울팁 포수 포구 25%, 나머지 75% 기존 루킹/헛스윙 삼진 중 선택.
- 주자 없는 일반 아웃(3F 등): 기존 연출 4종과 추가 연출 3종을 균등 선택. 즉 1루수 직접 처리·1루수→투수 송구·투수 직선타는 각 1/7 확률.
- 주자 있는 일반 아웃: 기존 안전한 연출 3종만 선택. 주자 있는 삼진에서도 파울팁은 가능.
- 확률은 경기 기록에 영향을 주지 않으며, 조정할 때도 아웃 판정 코드가 아닌 장면 선택 목록만 바꿉니다.

## 버전 격리
- 경기 저장: v3 전용 키 사용. v2·v1 저장을 읽어오기 위한 폴백 제공.
- 선수명단 저장: v3 전용 키 사용. 이전 v2 명단을 읽을 수 있음.
- 통산 기록: 다른 규칙 버전과 섞이지 않는 v3 전용 키 사용.
