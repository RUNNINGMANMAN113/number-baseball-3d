# NUMBER BASEBALL 3D: FULL COUNT — HOME RUNS WIN v1

기존 NUMBER BASEBALL 3D v42를 바탕으로 제작한 별도의 플레이 가능한 HTML 프로토타입입니다. **원본 v42를 덮어쓰지 않습니다.**

## 시작하기

이 ZIP의 내용 전체를 한 폴더에 압축 해제하고 Chrome/Edge 브라우저에서 다음 파일을 실행하세요.

- **index.html** — 2인용 로컬 대전. 한 기기를 번갈아 사용하며 수비팀만 비밀 숫자를 입력합니다.
- **ai.html** — 1인 vs AI 대전. 사람과 AI가 각각 공격·수비합니다.
- **attack.html** — 1인 홈런 챌린지. 9이닝 동안 정확한 3S를 최대한 많이 얻는 연습 모드입니다.
- **animation_engine.html** — 별도 3D 중계/6F 아웃 연출 엔진. 상위 HTML이 불러옵니다.

폴더 안의 파일을 서로 다른 경로로 이동시키지 마세요. 3D 그래픽은 Three.js CDN을 사용하므로 인터넷이 필요합니다. CDN 사용이 불가능한 환경에서는 중계 화면의 3D 부분이 제한될 수 있습니다. 게임은 브라우저를 닫기 전 자동 저장되며, 플레이 모드별·원본 v42별로 저장 공간이 분리됩니다.

## 새 승리 규칙

- **3S가 나오면 홈런 1개**가 기록됩니다. 타석 당시 주자 수와 관계없이 홈런 수는 **항상 1개**만 증가합니다.
- **일반 득점(R)**, 볼넷, 안타, 주루는 계속 기록되지만 승자를 결정하지 않습니다.
- 경기 종료 시 **홈런 수가 더 많은 팀이 승리**합니다. 예: 홈런 2:3이면 일반 득점이 100:3이라도 홈런 3개 팀 승리.
- 정규 이닝(3/5/7/9) 이후 홈런 수가 같으면 연장전, 최대 정규이닝+3이닝(최대 12회) 뒤 동점이면 무승부입니다.
- 홈팀이 정규 이닝 또는 연장에서 홈런 수를 앞서면 끝내기 판정이 가능합니다.
- 1인 홈런 챌린지는 상대팀 득점 승부가 아닌 홈런 개수 도전 모드입니다.

## 숫자·수비 규칙

- 0~9의 중복 없는 세 자리, 0으로 시작해도 가능. S·B·F 및 3F 즉시 아웃, 4B 출루 등 핵심 판정은 v42 기반입니다.
- **볼넷 후에는 새로운 숫자 변경권을 부여하지 않습니다.** 기존의 같은 투수 연속 볼넷에 따른 변경권도 제거했습니다.
- **3S 홈런 뒤에는 수비의 숫자 변경권**이 발생합니다. 수비가 숫자를 새로 설정한다면 원래 비밀 숫자의 **세 위치 모두 다른 숫자**여야 합니다. 기존 숫자 유지도 선택할 수 있습니다.
- v42의 별도 투수 교체·선발 비밀숫자 추가 사용 제약(선발 총 6개 + 불펜 10개 = 최대 16개)과 25구 조건은 유지됩니다. 이 모드가 숫자 변경을 **오직** 홈런에서만 허용한다는 뜻은 아닙니다.
- 같은 타자가 실제 같은 투수를 상대로 동일 추리 숫자를 누적 3회 이상 입력하지 못하도록 하는 v42 규칙은 유지됩니다.

## 6F 특별 아웃

- 실제 수비 **투수별로 F 숫자 개수**를 누적합니다. `1B2F`는 F를 **2개** 더합니다.
- 같은 투수가 비밀 숫자만 변경하면 누적 F는 유지하고, 실제 다른 투수가 투입되면 0으로 초기화합니다.
- 투구 시작 시 이미 **2스트라이크**, 이번 투구에 F가 1개 이상, 누적 F가 **6의 배수에 도달 또는 초과**하면 특별 아웃 처리합니다. 3F 즉시 아웃과 S에 의한 삼진 등 선행 판정은 우선합니다.
- 주자 없을 때 아웃 유형은 **포수 파울팁 삼진 40%**, **1루수 직접 아웃 30%**, **1루수→투수 1루 커버 20%**, **투수 직선타 포구 10%** 중 하나. 주자가 있을 때는 파울팁 삼진 유형을 사용하여 기존 주루 상태를 변경하지 않습니다.
- 확률은 **이미 확정된 아웃의 유형과 중계 장면에만** 영향을 줍니다. 3U, 3-1, 직선타 아웃은 공식 기록에서 삼진으로 계산하지 않습니다.

## 피치클락

- 타석 첫 숫자 입력 **60초**, 이후 입력은 **45초**.
- 시간 초과: 스트라이크 +1, 이미 2스트라이크면 삼진 아웃.
- 공수 교대·비밀 숫자 설정·수비 선택·중계 애니메이션·일시적인 숨겨진 탭·기록 창이 떠 있을 때는 카운트하지 않습니다.
- AI 대전에서는 사람의 공격 차례에만 피치클락을 적용합니다. 인공지능의 계산 시간은 규칙적으로 제한하지 않습니다.

## 검증 범위

자바스크립트 실행 테스트(2인용·AI 대전·1인용)에서 다음을 확인했습니다: 3S 홈런 기록 증가, 6F 특별 아웃, 피치클락 시간 초과 삼진, 득점에 무관한 홈런 수 승리 판정. AI와 사람을 대상으로 장기간 플레이테스트를 완료한 정식 상용 게임은 **아닙니다**. 웹 실행 환경에 따라 3D 그래픽과 로컬 파일 접근에 제한이 있을 수 있습니다.

## 개발자 파일

`patch_build.py`와 `test_game.py`는 게임 파일을 수정·검증할 때 사용한 개발 도구입니다. `patch_build.py`는 컴퓨터의 특정 경로에 원본 v42가 있는 환경에서 실행하도록 작성했으므로 일반 사용자는 실행할 필요가 없습니다.
