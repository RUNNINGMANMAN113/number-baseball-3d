# NUMBER BASEBALL 3D v35 · 고화질 유지 + 공격모드

기반: v34 고화질 렌더링 엔진, 해상도/프레임 제한 변경 없음.

## 실행
- `index.html`: 2인용
- `ai.html`: AI 대전
- `attack.html`: 1인용 공격모드 (9이닝, CPU 항상 수비)

선수 명단은 v34의 KBO 2026 기록을 그대로 사용합니다. 기존 v35(저화질 수정판)는 폐기하고, v34를 기반으로 v35를 새로 빌드했습니다. 컴퓨터는 3자리 서로 다른 무작위 비밀 숫자를 생성합니다. 이닝 교대 혹은 기존 게임의 적법한 교체 조건(홈런, 연속 4B, 투구 수 등)에서만 투수를 교체할 수 있으며, 투수 교체 시 82% 확률로 비밀 숫자를 변경하고 18%는 숫자를 유지합니다. 투수 교체 시도 여부는 투구 수/볼넷/홈런/이닝의 영향에 따른 확률로 결정합니다. 비밀 숫자는 판정과 저장 시스템에만 보관하고 화면에는 표시하지 않습니다.

## 중계 화면이 잠깐 하얗게 바뀌는 경우
3D WebGL/iframe 렌더링 오류를 이 환경에서 완전히 재현·수정하지 못했습니다. 그래픽을 낮추지 않는 대신 게임의 '지금 저장'을 누르고 브라우저 새로고침 후 '저장한 경기 이어하기'를 선택하라는 안내를 게임 화면에 추가했습니다. 저장 성공 배지가 표시되는지 확인해야 합니다. 공격모드 경기 저장·라인업 보관함·통산 기록은 기존 2인용/AI 대전과 별도 저장 키를 사용합니다. 게임 외의 브라우저·GPU 오류는 별도 분석이 필요합니다.

## 제약
브라우저가 탭 전체를 종료할 경우 자체 복구 불가. 게임은 브라우저 저장소 사용이 허용된 같은 주소에서 이어집니다. 중계 애니메이션/Three.js CDN 연결에 인터넷이 필요합니다.
