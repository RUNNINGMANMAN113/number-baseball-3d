# NUMBER BASEBALL 3D v34 — 2026 KBO 3경기 이상 선수 명단 게임 적용판

## 변경 내용
- v33 게임을 기반으로 선수 선택기의 데이터만 교체했습니다.
- **2026 KBO 정규시즌 누적기록에서 3경기 이상 출전이 확인된 531개 구단별 선수 항목**을 수록했습니다. 타자 264개, 투수 267개입니다.
- 10개 구단 각각 야수/투수 명단을 분리했고, 선수 버튼에 2026 시즌 출전 경기 수를 표시합니다.
- 삼성 구자욱/페덱/사토시 포함; 삼성 이승현 2명, 한화 박준영 2명은 출생연도로 구분했습니다.
- 시즌 도중 이적/교체 선수를 시즌 출전 구단에 포함할 수 있습니다.
- 기존 팀 선택, 검색, 선수 클릭을 통한 선발/후보 편성, 투수 선발, 중계, 점수판, 경기 규칙, 저장 기능을 유지합니다.
- **index.html (2인용)** 과 **ai.html (AI 대전)** 에 동일한 데이터를 내장했습니다.

## 실행
- 압축을 해제하고 `index.html` 또는 `ai.html`을 실행합니다.
- `animation_engine.html`은 두 HTML과 같은 폴더에 놓아야 합니다.
- 3D 엔진의 외부 스크립트에는 인터넷 연결이 필요할 수 있으나, KBO 선수 명단 자체는 HTML 안에 들어 있어 별도 로스터 다운로드가 필요하지 않습니다.
- ‘선수 선택하기 · KBO 2026’ → 구단 → 타자/투수 → 선수 이름 클릭. 검색창으로 이름을 찾을 수 있습니다.

## 검증 범위와 한계
- 이 명단은 **모든 경기 기록을 완전히 전수 검증한 최종 확정본이 아닙니다**.
- 시즌 누적기록/순위표에 등재된 3경기 이상 선수들을 기준으로 하고 있어, 안타 0인 야수, 탈삼진 0인 투수 등 누락 가능성이 남아 있습니다.
- 일부 공식 대조가 필요한 이름 및 경기 수가 있으므로 통계·선수 식별 목적으로 최종 인증된 데이터라고 표시하지 않습니다.
- 선수 기본 수비 포지션의 일부는 데이터 부족으로 ‘미확인’ 표기됩니다. 포지션은 라인업 화면에서 직접 변경할 수 있습니다.
- 동명이인과 이적 선수는 구단·역할·구분명을 유지했습니다.

## 파일
- `index.html`: 2인용 게임 (2026 명단 내장)
- `ai.html`: AI 대전 게임 (2026 명단 내장)
- `animation_engine.html`: 기존 3D 중계 엔진 (v33 유지)
- `KBO_2026_3G_roster.json`: 풀 로스터 JSON (선수별 경기 수)
- `KBO_2026_3G_roster_min.json`: 압축 JSON
- `KBO_2026_3games_roster_checked.csv`: 선수별 출전 기록 원본 CSV
- `roster_counts_v34.json`: 팀별 수록 건수
